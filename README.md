# FundScope — Mutual Fund Dashboard

Canonical development repository for FundScope, an Indian mutual fund research dashboard using MFAPI.

The existing application is being migrated here with its approved light interface, tests, calculation methodology, persistent history storage, and scheduled refresh workflow.

Current website: https://fundscope-research.patelvasuki.chatgpt.site

Market-data source: https://www.mfapi.in/

Historical coverage is limited to observations supplied by the source. Source NAV dates and successful synchronization timestamps are tracked separately.
